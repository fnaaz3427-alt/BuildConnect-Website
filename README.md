# BuildConnect Website Starter

Open `index.html` in a browser. The `assets` folder contains the four images provided for this website.
The first supplied apartment image is used in the hero/first page. The other three images appear in the “Every part of the journey” section (along with the apartment image).

The site includes responsive styling, CSS-based 3D visual effects, marketplace filters, demo listings, enquiry modal, and WhatsApp/email contact links. Sample listings are illustrative. The enquiry demo is front-end only; add a backend/database for live use.
